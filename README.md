# DV TASK-2 – Superstore Data Visualization

## About the Project

This project is based on **Superstore sales data**. The main purpose of this project is to analyze sales, profit, discount, delivery time, and category-wise performance using Python.

The project uses **Pandas, NumPy, Matplotlib, and Seaborn** for data analysis and visualization.

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Google Colab
* Jupyter Notebook

## Dataset

The project uses the **Superstore dataset** containing information about orders, sales, profit, category, discount, order date, and ship date.

## Data Processing

The following preprocessing steps are performed:

* Load the Superstore CSV dataset
* Check the first few records
* Check dataset information
* Generate descriptive statistics
* Convert Order Date and Ship Date into date format
* Calculate delivery days
* Check categories
* Check missing values

The project calculates **Delivery Days** using the difference between Ship Date and Order Date.

## Data Visualization

The project includes the following visualizations:

### 1. Sales by Category

Shows the total sales for each product category.

### 2. Sales Distribution

Displays the distribution of sales values using a histogram.

### 3. Profit by Category

Compares profit across different categories.

### 4. Sales Distribution by Category

Visualizes sales values for each category.

### 5. Profit Distribution

Shows the overall distribution of profit.

### 6. Profit Variation Across Categories

Uses a box plot to compare profit variation between categories.

### 7. Impact of Discount on Profit

A scatter plot is used to study the relationship between discount and profit.

### 8. Correlation Heatmap

A correlation heatmap is created for numerical columns to understand relationships between variables.
